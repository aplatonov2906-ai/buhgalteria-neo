# buhgalteria-neo.ru — сайт бухгалтерского обслуживания «НЕО»

Статический лендинг без бэкенда. Хостинг — GitHub Pages, домен `buhgalteria-neo.ru`.

## Состав

| Файл | Назначение |
|------|------------|
| `index.html` | Лендинг (вся вёрстка, стили и скрипты внутри одного файла) |
| `politika.html` | Политика обработки персональных данных (152-ФЗ) |
| `soglasie.html` | Согласие на обработку персональных данных |
| `robots.txt`, `sitemap.xml` | Индексация поисковыми системами |
| `favicon.svg` | Иконка сайта |
| `CNAME` | Привязка домена к GitHub Pages — не удалять |

## Настройка DNS у регистратора

Для корневого домена `buhgalteria-neo.ru` — четыре A-записи:

```
A   @   185.199.108.153
A   @   185.199.109.153
A   @   185.199.110.153
A   @   185.199.111.153
```

Для `www` — CNAME:

```
CNAME   www   aplatonov2906-ai.github.io.
```

DNS обновляется от 15 минут до нескольких часов. После этого в настройках репозитория
(Settings → Pages) нужно включить **Enforce HTTPS** — сертификат Let's Encrypt выпустится
автоматически и бесплатно.

## Обновление сайта

Правки в файлы → `git push` → GitHub Pages пересобирает сайт за 1–2 минуты.

## Что нужно сделать до запуска рекламы

1. Заменить заглушки: телефон, почту, адрес, ИНН и ОГРН (встречаются в `index.html`,
   `politika.html`, `soglasie.html`).
2. Подключить форму к обработчику на российском сервере — сейчас форма только показывает
   сообщение об успехе и никуда не отправляет данные.
3. Подать уведомление об обработке персональных данных в Роскомнадзор.
